## Featured Projects

### [EGFR Docking Validation](https://github.com/ppmferreira/egfr-docking-validation)

![Research](https://img.shields.io/badge/Research-Scientific%20Analytics-087E8B?style=flat-square)
![Data](https://img.shields.io/badge/Data-Public%20Scientific%20Sources-334155?style=flat-square)
![Methods](https://img.shields.io/badge/Methods-Benchmarking-0A66C2?style=flat-square)

A retrospective computational study evaluating molecular docking methods for EGFR inhibitors, using public datasets, curated ChEMBL activity data, RDKit, AutoDock Vina and DiffDock.

| Documented benchmark | Result |
| :--- | :---: |
| EGFR–inhibitor complexes | **11** |
| Vina pose recovery (RMSD ≤ 2 Å) | **10/11** |
| DiffDock pose recovery (RMSD ≤ 2 Å) | **8/11** |

**Key competencies:** data curation, benchmarking, reproducibility, computational analysis and scientific interpretation.

The project includes documented methods, scripts, results and an experimental dashboard, with discussion of random-seed sensitivity and methodological limitations.

**Scientific limitations:** these retrospective pose recovery results do not establish binding affinity, selectivity, clinical efficacy or successful drug discovery. Ranking enrichment validation remains incomplete.

[![Repository](https://img.shields.io/badge/Explore-Repository%20%26%20Report-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/ppmferreira/egfr-docking-validation)

## My Analytical Approach

| Stage | Purpose |
| :--- | :--- |
| **01 — Understand** | Define the business problem and the decision to support. |
| **02 — Collect** | Identify reliable, documented real-world data sources. |
| **03 — Validate** | Clean data, assess quality and document limitations. |
| **04 — Analyze** | Explore patterns, compare indicators and visualize findings. |
| **05 — Communicate** | Translate evidence into clear, actionable insights. |
| **06 — Evaluate** | Distinguish findings from assumptions and assess recommendations. |

I use AI-assisted workflows where appropriate, emphasizing human review, methodological transparency and validation.
